# AXVELL Direct Designer V6.1

ZX-4R / ZX-4RR decal design prototype.

## Current features
- BLACK / WHITE / GREEN
- SIDE A / SIDE B / FRONT A / FRONT B
- Direct design overlay on the bike
- DRAW / STRIPE / BLOCK / CIRCLE / TEXT / AX logo
- Drag, size, rotate, opacity
- Mirror Pair between opposite views
- Undo / Redo / Save / PNG export
- High-resolution local base-image import
